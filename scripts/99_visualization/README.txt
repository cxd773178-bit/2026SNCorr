Visualization and Outputs

Run ../1_maincode/1.1_RSA_main.Rmd before executing scripts 99.1–99.4 in this directory.

Outputs are organized as follows:

results/behavior_network/: behavioral distributions and network visualization

results/jaccard/: Jaccard similarity heatmap and summary tables

results/descriptive_qap/: QAP results and centrality correlation heatmaps

results/rsa/: RDM and centrality–behavior correlation figures
